# DeepSeek 联网搜索配置

## 配置

打开项目根目录 `.env`，仅将 `DEEPSEEK_API_KEY=xxxxxxxx` 中的
`xxxxxxxx` 替换为你自己的 DeepSeek API 密钥。不要发送密钥给他人。

```dotenv
SEARCH_PROVIDER=deepseek
DEEPSEEK_API_KEY=xxxxxxxx
DEEPSEEK_SEARCH_MODEL=deepseek-v4-flash
```

后端启动时自动读取该文件。系统已有的同名环境变量优先于文件；
若此前配置过环境变量，请保持一致或移除旧值。前端不会收到密钥。
`.env` 已加入 Git 忽略规则，提交模板请使用 `.env.example`。
分享项目压缩包时必须排除 `.env`。

## 启动与验证

如果后台已启动，先结束本项目的后端进程，再执行 `start-background.ps1`。
脚本检测到现有服务会直接退出，不会自动重新加载密钥。
不确定进程时，可以保存工作、重启电脑，再运行该脚本。

访问 `http://127.0.0.1:4321/`。
接口 `/api/grad/research/schools` 的 `hasSearchKey: true`
只表示读取了非占位密钥，不表示账户已获得搜索权限。

实际验证：选择中国科学技术大学，输入“计算机视觉”进行导师检索。
首次查询须调用收费接口；占位符不会产生接口请求。
搜索结果仍会经过官方域名过滤和网页采集，研究方向、联系方式由
现有原文解析器提取。模型普通文字回答不作为教师事实入库。

## 限制

- 对接的是 DeepSeek 原生 `web_search_20250305`，不是普通聊天补全。
- 默认模型参照官方适配器；账户能否使用模型和工具，需填入真实密钥实测。
- 每条搜索最多使用工具 2 次，导师查询并发上限 2；同一次查询可能扩展
  多条中英文检索词，每条均可能产生模型费用。
- 单条模型请求超时 60 秒，不自动重试或静默切换其他收费提供商。
- 已有资料缓存继续生效；配置密钥后，之前同条件的缓存可能保留最多 10 分钟。
- HTTP 401 检查密钥，402 检查余额，429 稍后重试；
  400 或没有搜索结果块时检查模型和工具权限。不会将无搜索依据的生成内容伪装成结果。
- 本次仅使用占位符和模拟响应测试，不代表真实账户联网验收已通过。

## 实现依据

接口协议参考 DeepSeek 官方开源搜索适配器：
https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/web/web-search-deepseek

本项目自行实现最小 HTTP 适配器，未安装或复制该仓库源码。
官方页面提取、证据关联、缓存及用户界面继续使用项目已有实现。
